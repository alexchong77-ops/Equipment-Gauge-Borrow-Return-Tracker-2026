Equipment & Gauge Borrow/Return Tracker

How to use the shared tool accountability system.

1. Sign in

Use the username and password provided by your Administrator. The first time you sign in, set a new password if prompted. Staff can record borrows and returns; Administrators can manage user accounts.

2. Find a gauge

Open Gauge inventory to browse pin trays and other gauge groups. Administrators can register and edit equipment details there. Staff can view registered equipment details after selecting an item in the borrow form. A gauge must have a current calibration record before it can be issued.

3. Record a borrow

Select Record borrow, then choose the staff member, tool, job order, drawing, machine/work center, expected return time, and issue condition. Take a clear phone photo of the gauge size and confirm it matches the selected tool before validating the borrow.

4. Monitor loans

The Monitoring table shows open, overdue, due-soon, and returned loans. Search by staff name, job order, drawing, or other displayed loan details. Open a record to view its details and evidence photos.

5. Record a return

Choose Record return on an open loan. Select the physical condition, take a return photo, confirm the size and visual check, add notes if needed, then save the return.

Condition options: Excellent (No Wear/Oiled); Clean & Good (Standard Condition); Minor Wear (Slight cosmetic scuff); Recalibrate (Dropped or burred); Missing/Under Investigation.

6. Staff, calibration, and records

Staff & settings: Administrators can add or update user accounts. Calibration: open a gauge slot to set its certificate reference and due date. New records generate an internal reference and default to 30/12/2027; use the reference on the issued calibration certificate when available. Audit trail: review who recorded borrow, return, staff, and calibration changes.

Alerts and backups

Overdue and due-soon browser notifications work while the tracker is open and permission is enabled. Use Export records regularly. The JSON export does not include camera photos; those are stored with the tracker data and must be backed up separately.
